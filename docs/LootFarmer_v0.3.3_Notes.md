# LootFarmer v0.3.3 — recent finds

Apply over v0.3.2. Coins still credit the wallet, but coin-only rewards no longer produce history entries. Recent finds and history show gem quantities and items, without coin counts (including sale entries). Legacy coin-only history is hidden before selecting the three recent entries, so it does not crowd out actual finds. Saved history remains compatible; no save schema or economy changes.

Validation: existing gameplay and UI probes passed on Godot 4.5.1; declared project baseline remains unchanged.
