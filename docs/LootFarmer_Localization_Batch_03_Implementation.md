## B. Complete precisely five natural-language PO files

| Locale | Catalog | Linguistic and technical requirements |
|---|---|---|
| Turkish | `localization/tr_TR.po` | Native-sounding Turkish RPG terminology, agglutinative suffixes, vowel harmony, case/possessives, predictable formatting with variable values, and locale-appropriate commands. |
| Indonesian | `localization/id_ID.po` | Natural, concise Indonesian game vocabulary (not awkward literal English); clear imperatives, unambiguous item/action distinctions and consistent stylistic register. |
| Vietnamese | `localization/vi_VN.po` | Correct Vietnamese tone marks, diacritic combinations, idiomatic phrasing, readable short UI copy and complete font glyph coverage. |
| Thai | `localization/th_TH.po` | Idiomatic Thai, reliable word breaks/wrapping, glyph composition and shaping, non-clipped ascenders/descenders and sufficient line height, touch-friendly labels. |
| Hindi | `localization/hi_IN.po` | Natural Hindi RPG copy, gender/number and postpositions, correct Devanagari conjuncts/matra shaping, wrapping and vertical metrics. |

For **every** catalog:

- Review all existing draft strings as untrusted; translate missing entries and correct misleading/unnatural ones. Translate **meaning and player intent**, not English word order. Read complete sentence contexts and actual gameplay screens when terms are ambiguous.
- Require **100% key parity** with the *current* English catalog: no missing/extra/duplicate/fuzzy/empty entries; correct PO grammar, contexts, format specifiers, ordering/types, escaped-percent conventions, interpolation, intentional line breaks and markup. Test real formatting, not regex matching alone.
- Check all dynamic number/quantity strings. **English has limited PO plural metadata**, so where necessary phrase sentences in ways that are grammatical for any integer without inventing unsupported plural APIs. Manually review multi-placeholder sentences for semantic ordering and correct case/gender. When real plural forms are supported by the current renderer, use them properly.
- Keep game/product names, exact symbols, IDs and common abbreviations unchanged only when intentional. Record **each English-identical string with its rationale** in the existing allowlist approach. Do not silently leave English sentences as fallback.
- Add decisions to the shared `docs/LootFarmer_Localization_Glossary.md`. Perform a complete semantic review of high-impact strings (tutorial commands, equipment, combat, Prestige, review invitations) and independently examine the five languages rather than mapping through another translated language.
- State the reviewer accurately: AI/agent review and automated validation are **not** native-speaker approval.
